# Docker من الصفر

موقع برزنتيشن تعليمي بالعربية يشرح Docker بالكامل: Images، Containers، Dockerfile، Volumes، Networks، Compose، وأمثلة عملية — مع رسومات واختبار بمستويات.

## اللينك المباشر

بعد النشر على GitHub Pages:

**https://m7moud2.github.io/docker-presentation/**

## التشغيل محليًا

```bash
npm install
npm run dev
```

ثم افتح الرابط اللي هيظهر في الطرفية (عادةً http://localhost:5173).

## البناء للإنتاج

```bash
npm run build
npm run preview
```

للنشر على GitHub Pages:

```bash
GITHUB_PAGES=true npm run build
```
